Generated by `tools/hw/gen_kicad.py` from `hardware/netlist/mainboard.py` — edit the netlist, re-run,
don't hand-edit the generated files until layout work starts (then the netlist becomes the record and
the .kicad_pcb the working file).

```
py tools/hw/gen_kicad.py hardware/netlist/mainboard.py hardware/kicad/mainboard
```

| File | Content |
|---|---|
| `mainboard.kicad_pro/.kicad_sch/.kicad_pcb` | project · schematic (label-connected, one symbol per part) · PCB |
| `board_outline_draft.dxf` | casing inner wall inset 1.5 mm — already on Edge.Cuts; true-offset it in KiCad before fab |
| `casing_inner_wall.dxf`, `casing_outer_wall.dxf` | reference contours (User.Comments) |

PCB coordinates: the **axle centre is at (150, 150) mm** in KiCad; +x toward the tail, +y up in the
netlist = down in KiCad (handled by the generator). Edge.Cuts includes the Ø 38 axle cut-out.
Unrouted by design: placement is verified against the casing; routing is GUI work (Power netclass
1.5 mm, Default 0.25 mm are preset in the project).
