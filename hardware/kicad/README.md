# KiCad project — Z-Class v10 mainboard (generated)

Generated by `tools/hw/gen_kicad.py` from `hardware/netlist/mainboard.py` — edit the netlist, re-run,
don't hand-edit the generated files until layout work starts (then the netlist becomes the record and
the .kicad_pcb the working file).

```
py tools/hw/gen_kicad.py hardware/netlist/mainboard.py hardware/kicad/extended/mainboard
```

| File | Content |
|---|---|
| `mainboard.kicad_pro/.kicad_sch/.kicad_pcb` | project · schematic (label-connected, one symbol per part) · PCB |
| `board_outline_draft.dxf` | casing inner wall inset 1.5 mm — already on Edge.Cuts; true-offset it in KiCad before fab |
| `casing_inner_wall.dxf`, `casing_outer_wall.dxf` | reference contours (User.Comments) |

PCB coordinates: the **axle centre is at (150, 150) mm** in KiCad; +x toward the tail, +y up in the
netlist = down in KiCad (handled by the generator). Edge.Cuts includes the Ø 38 axle cut-out.
Netclasses come from the netlist (Default 0.15 mm clearance / 0.25 mm track, Rail 0.6, Motor 0.5,
Audio 1.0, Power 1.2). Routing recipe: `tools/hw/prep_route.py --route-5v` → Freerouting
(`tools/freerouting/`, `-mp 16 -mt 6`) → `tools/hw/post_route.py` (SES import + GND stitching), last
nets by hand in pcbnew. KiCad DRC is the judge — Freerouting's on-screen "violations" count is not.

## Two board variants (Aug 2026)

| Folder | Outline | Use |
|---|---|---|
| `extended/` | teardrop 152 × 125 mm — casing extended 15 mm downward | the roomier layout; auto-placed |
| `compact/`  | teardrop 152 × 110 mm — the original casing | **the built board**: hand-placed (James), 4-layer routed, DRC 0 errors, JLCPCB package r7 (`hardware/fab/`) |

Both are generated from the **same netlist** (`hardware/netlist/mainboard.py`) and are kept in sync
with `tools/hw/sync_parts.py <hand-placed.kicad_pcb> <freshly-generated.kicad_pcb>` — it updates
parts/nets/footprints and never moves anything. Regenerate with
`py tools/hw/gen_kicad.py hardware/netlist/mainboard.py hardware/kicad/<variant>/mainboard`
(the outline is read from `<variant>/board_outline_draft.dxf`). Fab package:
`.\tools\hw\fab_outputs.ps1 compact` (or `extended`) → `hardware/fab/<variant>-<date>/`.
